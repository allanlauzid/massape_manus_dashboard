# Site estático da Massapê

Este pacote contém um site estático pronto para publicação no GitHub Pages.

## Arquivos principais

- `index.html` — painel estratégico acessível e didático.
- `dossie-massape-mario-wanderley.html` — dossiê documental convertido para HTML.
- `benchmark-sites-chocolate-massape-mario-wanderley.html` — benchmark convertido para HTML.
- `analise-critica-massape-posicionamento-online.html` — análise crítica da marca e do posicionamento online.
- `pesquisa-claude-mercado.html` — pesquisa complementar feita pelo Claude (diagnóstico de mercado e plano), separada da pesquisa do Manus.
- Os dois arquivos `.md` originais também estão incluídos como fonte editável.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Acesse **Settings → Pages**.
4. Escolha **Deploy from a branch**, branch `main` e pasta `/root`.
5. Salve e aguarde o endereço público.

O arquivo `index.html` já é a página inicial. Estilos e comportamento compartilhados ficam em `assets/site.css` e `assets/site.js`, usados pelas quatro páginas. Não altere os nomes dos arquivos HTML, pois os links internos dependem deles.
